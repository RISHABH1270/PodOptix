STEP 1
EnsureDatabase(databaseURL)
Connects to the default postgres DB and runs CREATE DATABASE podoptix if absent. Must run before SyncSchema — target DB may not exist yet.
STEP 2
SyncSchema(databaseURL)
Runs all migration files in sequence. Skips already-applied. Auto-fixes dirty state from a previous crash recovery.
STEP 3
New(databaseURL) *Store
Allocates pgxpool.Pool in heap. Returns *Store — a pointer on the stack holding the heap address of the pool. Settings: MaxConns=10, MinConns=2, MaxConnLifetime=1h, MaxConnIdleTime=30m. Dead connections replaced automatically by pgxpool on next use.

Used by /readyz readiness probe to verify the database is alive before the pod receives traffic.

Collection + Computation
Collector → Compute → Recommender
collector / compute / recommender
4 Prometheus queries
▾
HTTP
collector.Collect(ctx, lookbackWindow)
4 Prometheus queries: CPU usage (query_range) · Memory usage (query_range) · CPU limits (instant) · Memory limits (instant). Results merged by (namespace, pod, container) key into []*ContainerMetrics.
MATH
compute.ComputeP99(values []float64)
Sort values → index = ceil(0.99 × n) − 1. Never modifies the original slice. Returns error on empty dataset.
GEN
recommender.GenerateAll(clusterID, metrics)
For each container: if CPU or Mem values empty → status = new_service. Otherwise: p99CPU × 2 → ceil → RecommendedCPULimit. Same for memory. Returns []*Recommendation ready for UpsertRecommendation.
