STEP 1
EnsureDatabase(databaseURL)
Connects to the default postgres DB and runs CREATE DATABASE podoptix if absent. Must run before SyncSchema — target DB may not exist yet.
STEP 2
SyncSchema(databaseURL)
Runs all migration files in sequence. Skips already-applied. Auto-fixes dirty state from a previous crash recovery.
STEP 3
New(databaseURL) *Store
Allocates pgxpool.Pool in heap. Returns *Store — a pointer on the stack holding the heap address of the pool. Settings: MaxConns=10, MinConns=2, MaxConnLifetime=1h, MaxConnIdleTime=30m. Dead connections replaced automatically by pgxpool on next use.
PROBE
Ping(ctx) error
Used by /readyz readiness probe to verify the database is alive before the pod receives traffic.
CLOSE

Graceful shutdown called via defer db.Close() in main.go.

Layer 4 · Data Access
Store — cluster.go
internal/store/cluster.go
6 functions
▾
INSERT
SaveCluster(ctx, *models.Cluster) error
Inserts a new cluster row. Hard-codes last_synced_at = NULL — sync state is owned entirely by UpdateClusterHealth.
SELECT
GetCluster(ctx, clusterID string) (*models.Cluster, error)
Full row scan by primary key. Returns error if row absent so API can return 404.
SELECT
ListClusters(ctx) ([]*models.Cluster, error)
All rows ordered created_at DESC. Returns empty slice, never nil.
UPDATE
UpdateCluster(ctx, *models.Cluster) error
Updates config only: name, url, token, lookback_window. Does NOT touch status or last_synced_at. RowsAffected == 0 → error.
UPDATE
UpdateClusterHealth(ctx, clusterID, status string, collectedAt time.Time) error
Sole owner of status + last_synced_at. Called only by the background sync goroutine and re-ping path. No other code path sets these fields.
DELETE
DeleteCluster(ctx, clusterID string) error
Hard delete by primary key. RowsAffected == 0 → error → API returns 404.
